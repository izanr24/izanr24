## 🚀 Sobre mí

Soy **desarrollador de software Full-Stack**, apasionado por la tecnología y por crear aplicaciones que sean útiles, funcionales y escalables.

Me gusta trabajar tanto en el **backend** como en el **frontend**, conectando APIs, bases de datos e interfaces para construir aplicaciones completas.

Actualmente sigo mejorando mis conocimientos y explorando nuevas tecnologías, especialmente en el ecosistema **Java + Spring Boot + Angular**, además de herramientas relacionadas con **Docker, bases de datos, automatización e inteligencia artificial**.

* 💻 Desarrollo de aplicaciones **Full-Stack**
* 🚀 Creación de proyectos que resuelven problemas reales
* ☕ Desarrollo backend con **Java y Spring Boot**
* 🅰️ Desarrollo frontend con **Angular, TypeScript, HTML y CSS**
* 🗄️ Trabajo con **bases de datos SQL y NoSQL**
* 📦 Contenedores y entornos con **Docker**
* 🤖 Explorando **IA, APIs y automatización**
* 📚 Aprendiendo y mejorando continuamente
